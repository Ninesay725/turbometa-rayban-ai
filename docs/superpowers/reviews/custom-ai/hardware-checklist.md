# 自定义 AI 真机与真实服务检查表

以下项目本轮均未验证；模拟器没有真实眼镜、QQ/网易云/汽水账号或模型服务密钥。

- [ ] 在“自定义 AI 设置”填自己的兼容 Chat Completions 地址、模型名和密钥；分别测试中文问答、翻译、错误密钥提示。模型不支持工具或图片时关闭相应开关。
- [ ] 配对 Display、启用开发者模式与 DAT Wearables App 后，测试中文长回复分页、按钮和朗读；确认声音从目标眼镜输出。系统听写是否可用、是否使用眼镜麦克风须独立核实。
- [ ] 拍照提问：首次相机授权往返、允许后重试、识图；退出、取消、折叠或断连时停止请求与镜片输出。已记录的 DAT 快速会话重启压力问题仍待 SDK/硬件验证。
- [ ] 开启通知访问，单独允许 AI 通知并选择微信或其他应用；用测试消息验证指定应用筛选、锁屏隐藏、删除、关闭授权后清空与停止朗读。只把愿意发给该模型服务的通知加入允许列表。
- [ ] 分别先在网易云、汽水、QQ 音乐播放，再测试播放/暂停、上一首/下一首及指定应用选择；应用未发布媒体会话/动作时应提示不可用，不改控其他应用。
- [ ] 在自己的 OpenClaw 服务器确认版本，选择匹配兼容方式、批准配对及相机命令，测试文字/图片、镜片回答、断网重连、清除本地配对凭据再配对。本次只升级 App 客户端，未检查或升级远程服务器。

API 密钥在手机内输入，不发送到聊天或进度报告。网关节点聊天在重新订阅/重连后使用新会话，避免过期回复串入下一轮；手机中的当前聊天列表不代表服务器保留同一上下文。
