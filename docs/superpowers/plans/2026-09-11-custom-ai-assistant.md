# 自定义 AI、通知摘要、QQ 音乐与 OpenClaw 兼容

用户已确认功能范围并授权常规实现选择。沿用 android-v2；不修改原始未提交工具配置或交接文件。

## 设计

- 在 App 增加独立自定义 AI 入口：配置 OpenAI-compatible Chat Completions URL、模型、加密 API key，支持文字、图片、工具能力开关及回答朗读。兼容协议不等于支持所有厂商专有 API；无图片/工具能力的模型仍可文字对话、翻译和通知摘要。
- 复用 DAT 单会话、取图、Display、TTS 与 Android 媒体会话；不替换系统 Meta AI。会话在助手页面前台使用，离开/取消终止请求与朗读，不新增后台自主代理。
- 工具仅允许拍照、自己的卡片、已允许的音乐应用。通知摘要为明确入口，只读用户另行授权的应用通知；摘要请求不携带可执行其他动作的工具，防止通知文字变成设备指令。内容仅内存保留并有上限，不写日志/磁盘。
- QQ 音乐加入默认媒体包；已有明确自定义允许列表不被覆盖。
- 对照 OpenClaw 当前官方协议/发布源码修正本项目客户端，保留明确可测试的旧协议兼容；没有用户服务器地址/访问证据时不声称已升级服务器。

## 任务与负责边界

1. 主线程：HTTP 客户端、受限工具循环、设备工具适配、回归测试、集成与整体验证。
2. UI 分工：自定义 AI 设置、聊天/语音入口、导航，复用既有朗读与显示。
3. 桥接分工：QQ 音乐、选定应用通知内存收集/权限收回、助手媒体操作。
4. OpenClaw 分工：当前协议审查、客户端兼容修复、协议测试与报告。
5. 范围审查、Debug/Release 测试与构建、模拟器检查、更新进度和真机待验清单。
